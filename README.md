## 📝 Sobre o Projeto

A **Calculadora Automática** é um exercício de lógica e manipulação de DOM (Document Object Model). O objetivo foi criar uma interface funcional onde o usuário interage com botões numéricos e operadores, e o JavaScript processa essas entradas para exibir o resultado instantaneamente, simulando o comportamento de calculadoras profissionais.

---

## 🚀 Diferenciais Técnicos e Funcionalidades

* **Lógica de Operação em Tempo Real:** Processamento imediato das entradas do usuário utilizando as funções do motor V8 do JavaScript.
* **Interface Intuitiva:** Design focado em usabilidade, com feedback visual a cada clique nos botões.
* **Manipulação de Eventos:** Utilização de *Event Listeners* eficientes para capturar a interação do usuário e atualizar o visor da calculadora dinamicamente.
* **Design Responsivo:** A estrutura foi pensada para ser utilizada tanto em telas de computadores quanto em dispositivos móveis.
